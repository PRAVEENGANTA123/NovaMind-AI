# NovaMind AI v2.0

## Project Overview

**Project Name:** NovaMind AI

**Developer:** Ganta Praveen Kumar

**Project Type:** Intelligent Multi-Agent AI Workspace

---

## Problem Statement

Users currently rely on different applications for AI chat, PDF reading, web search, website summarization, note-taking, and document analysis. Switching between multiple tools reduces productivity and makes knowledge management difficult.

---

## Proposed Solution

NovaMind AI combines these capabilities into a single AI-powered workspace.

Users can:

- Chat with AI
- Read PDF documents
- Read website URLs
- Search the Web
- Build a Knowledge Library
- Use specialized AI Agents
- Manage chat history
- Access analytics
- Use an Admin Dashboard

---

## Project Goals

- Build a professional AI workspace.
- Develop reusable software modules.
- Store user data securely using MongoDB.
- Integrate Google Gemini AI.
- Support PDF and URL understanding.
- Provide a modern, responsive interface.
- Prepare a complete internship and academic project.
